# US-27.3: Fix covariance-matrix date alignment

**Epic:** Epic 27 — Financial Calculation Correctness
**PRD:** [`epic-27-financial-calculation-correctness.md`](../prd/epic-27-financial-calculation-correctness.md)
**Status:** Backlog
**Last updated:** 2026-07-05

## Story

As a **portfolio researcher**, I want risk-contribution covariances computed
over date-aligned return pairs, so that risk shares, top-N concentration, and
both HHIs are built from real co-movement instead of accidentally shifted
series.

## Context (audit finding F4)

`analytics/risk.py` `_compute_covariance_matrix` builds each cell as:

```python
left_values  = [returns[left][d]  for d in dates if d in returns[left]]
right_values = [returns[right][d] for d in dates if d in returns[right]]
```

Each list is filtered **independently**. If the two symbols are missing
*different* dates but end up the same length, `zip` inside
`_sample_covariance` pairs returns from different calendar days — a silently
wrong covariance. (Different lengths at least yield `None`.) A single
provider gap on different days for two symbols in the 60-day window is enough
to trigger it.

Blast radius: `_build_factor_risk_contributions` and
`_build_position_risk_contributions` → variance contributions, `risk_share`,
`top_*_risk_share`, `factor_hhi`/`position_hhi`, `RiskConcentrationSnapshot`
(Dashboard Risk Summary card + diagnostics payload).

Correct behaviour: compute each cell over the pair's **intersected** date set
(`dates ∩ left ∩ right`), falling to `None` below 2 observations — the same
pairing discipline `analytics/correlation.py` already uses. (Alternative:
restrict the whole matrix to the all-symbols-common grid; decide and document
— pairwise intersection preserves more data and matches the correlation
module's convention.)

Implementer must read:
- `analytics/risk.py` `_compute_covariance_matrix`, `_sample_covariance`, and
  both `_build_*_risk_contributions` callers (window-date construction).
- `analytics/correlation.py` `pearson` — the existing pairwise-drop pattern.
- `docs/finance/financial-methodology.md` §Risk Contribution and Concentration.

## Acceptance criteria

  is missing date d2 (equal lengths, different coverage) produces the

- [ ] AC2 — Cells with < 2 overlapping observations are `None` (unchanged
  fail-closed floor).
- [ ] AC3 — The diagonal (variance) is computed over the symbol's own window
  dates, unchanged for full-coverage fixtures — behaviour-neutral when no
  dates are missing (existing tests + goldens hold without regeneration).
- [ ] AC4 — Methodology §Risk share gains one sentence stating the pairwise
  date-intersection convention.
