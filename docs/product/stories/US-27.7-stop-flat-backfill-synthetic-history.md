# US-27.7: Stop flat back-filling synthetic history before a symbol's first quote

**Epic:** Epic 27 — Financial Calculation Correctness
**PRD:** [`epic-27-financial-calculation-correctness.md`](../prd/epic-27-financial-calculation-correctness.md)
**Status:** Backlog
**Last updated:** 2026-07-05

## Story

As a **portfolio researcher**, I want synthetic-history analytics to exclude
(and disclose) the part of the window a holding has no price history for,
instead of pretending the holding traded flat, so my volatility, VaR,
drawdown, and correlation numbers aren't systematically understated.

## Context (audit finding F8)

Both daily-state builders back-fill prices **before** a symbol's first
available quote with the first quote (`first_price`):

- `services/diagnostics_engine.py` `_build_synthetic_snapshot_history_states`
  (~line 745) — feeds the stress, drawdown, distribution, and
  multi-benchmark-correlation engines plus diagnostics.
- `engine/portfolio_state.py` `build_daily_states` (~line 58) — the
  broker-truth path (dashboard history, drift).

A holding listed 30 days ago inside a 252-day window contributes a **flat
price for 222 days**: fabricated zero returns that dilute portfolio
volatility, compress the VaR/CVaR tails, shrink drawdowns, and distort every
correlation involving the synthetic portfolio series. The methodology forbids
exactly this ("null gaps must propagate as null, not be filled"; "never
fabricate").

Design decision to make in T-27.7.1 (record the choice + rationale in the
methodology):
- **Option A:** value the position only from its first quote onward (position
  enters the portfolio series mid-window; portfolio return before that is
  computed over the covered subset, with the coverage gap surfaced in
  trust/metadata).
- **Option B (recommended for the synthetic engines):** shorten the effective
  window to the latest first-quote across holdings above a de-minimis weight,
  and report the effective window + excluded span. Deterministic, easy to
  disclose, no weight-jump artifacts mid-series.
- Forward-fill of *interior* gaps (last known price carried ≤ a few days) is a
  separate, defensible convention — keep it, but name a maximum carry and
  document it.

This is the widest-blast-radius story in the epic: goldens **will** change
for any fixture containing a short-history symbol. Land after US-27.1–27.3.

Implementer must read:
- Both state builders + every engine consuming them (stress / drawdown /
  distribution / correlation / intra-correlation / diagnostics / dashboard /
  drift).
- Methodology: §Indexed Return Series edge cases, §Value-at-Risk (the
  `MIN_DAILY_OBSERVATIONS` floor interacts with a shortened window),
  §Drawdown episode decomposition ("position added after t_peak" edge case —
  must keep working).
- `docs/architecture/system-architecture.md` truth-class section.
