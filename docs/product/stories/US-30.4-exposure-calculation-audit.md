## Story

As a **portfolio researcher**, I want every number on the Exposure tab verified
against the methodology before anyone changes it, so that the fixes that follow
are grounded in recorded, reproducible findings rather than guesswork — the
same discipline that made Epic 27 and the drift fixes trustworthy.

## Context

US-30.1..30.3 fixed the six verified drift findings (F-1..F-6). The rest of the
Exposure tab — rolling correlation & beta, concentration/HHI, factor
attribution, factor drift summary, multi-benchmark correlation, intra-portfolio
correlation heatmap, ETF look-through / market overlap — has never had an
Epic-27-style correctness audit.

This story is **audit only**: verify each displayed number against
`docs/finance/financial-methodology.md`, reproduce every claim against the
committed `docs/IB2026.csv` portfolio where possible, and record findings in
the PRD's table with file:line evidence. **No fixes are applied** — that is
US-30.5, scoped from this table. Findings-first is what kept Epic 27 honest:
the record is written before anyone is tempted to make a number look right.

Implementer must read: `docs/finance/financial-methodology.md`
(§Rolling Pearson Correlation, §Beta, §R², §Multi-Benchmark Correlation,
§Intra-Portfolio Correlation, §Factor Return Attribution, §Risk Contribution
and Concentration, §Currency Exposure, §Synthetic History Coverage Rule);
`app/analytics/risk.py`, `app/analytics/correlation.py`,
`app/analytics/attribution.py`, `app/analytics/overview.py`;

## Notes / decisions

- **F-7 is the epic's second Critical.** The correct total is not a matter of
  opinion: FX-converting the positions with the statement's own implied rates
  reproduces the statement's own stock total ($61,238.53) to the cent, while
  the code's raw mixed-currency sum yields $58,588.76. The statement is the
  arbiter, so the finding is not a modelling preference.
- **F-10 is a doc-vs-doc contradiction, not only a code bug.** US-30.1 rewrote
  §Indexed Return Series to use the market-value chain on the no-ledger path;
  §Rolling Pearson Correlation still specifies the cash-flow-neutral
  `total_portfolio_value` chain. Today's code matches its own doc section in
  both places — so US-30.5 must first decide which basis is right for a
  synthetic current-holdings series, then move one doc and one code path.
  Recommendation recorded in the PRD: exclude cash (market-value chain), since
  the synthetic convention projects *holdings* backwards and today's cash
  balance was never held on those historical dates.
- No new formula is introduced by this story, so no academic citation is
  required. F-7's remediation reuses `statement_totals.fx_rates` (US-28.1
  broker truth, already plumbed to the drift engine in US-30.2).
