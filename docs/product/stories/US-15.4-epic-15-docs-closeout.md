## Story

As a **portfolio researcher** (and as an agent picking up this
product six months from now), I want the drawdown-decomposition
fields shipped in US-15.1/15.2 to be traceable from the UI surface
back to the response schema, the methodology formula, and the
academic citations — and I want the shipped-state inventory +
epic roadmap to reflect the new Contributors drawer so that
Epic 15 closes cleanly.

## Context

US-15.1 (Done, commit `9e6e967`) shipped the backend: every
`DrawdownEpisode` now carries `top_contributors`,
`other_contribution_pct`, `decomposition_residual_pct`, and
`decomposition_trust ∈ {'synthetic', 'partial', 'unavailable'}`.
The new `decompose_drawdown_episode()` function in
`app/analytics/drawdown.py` implements arithmetic Brinson-style
attribution under the synthetic-history convention.

US-15.2 (Done, commit `9157981`) shipped the frontend:
`DrawdownAnalyticsCard.tsx` gained an expandable per-episode
Contributors drawer (Symbol / Weight @ Peak / Return /
Contribution columns; "Other" aggregate + "Residual
(unexplained)" rows; partial-trust caption; disabled toggle when
decomposition unavailable; responsive).

US-15.3 was cancelled 2026-06-04 — the existing
`RollingFactorLoadingsCard` on the Dashboard tab already covers
the factor-drift visualization use case, so the originally-planned
new chart would have duplicated shipped functionality. Strikethrough
markers were already added to the PRD, roadmap, and stories README
at cancellation time.

This is a pure docs-reconciliation story. No code, no tests, no
methodology change. After it ships, Epic 15 closes.

## Notes / decisions

- **Pure docs reconciliation.** Five doc artifacts touched:
  `risk-fields.md` (new subsection), `financial-methodology.md`
  (verify-only, fix if drift), `current-product-state.md`
  (extend Risk-tab Drawdown bullet), `epic-roadmap.md` (flip +
  slice log), `stories/README.md` (status + section marker).
  Zero code, zero tests.
- **US-15.3 cancellation is already documented** in the PRD,
  roadmap, and README via strikethrough markers
  (updated 2026-06-04 during the cancellation pass). This
  story doesn't need to re-document the cancellation — just
  preserve those markers and close cleanly around them.
- **Why extend `risk-fields.md` rather than create a new doc.**
  The Drawdown card already lives under `risk-fields.md`'s
  Drawdown Analytics section (added in US-13.5). The
  decomposition fields are an extension of `DrawdownEpisode`,
  not a new engine — so they belong in the same place. Creating
  a new contract doc would fragment the Drawdown card's
  documentation across two files.
- **Methodology verification is judgement work** — only a
  careful reader can confirm that the formula text matches the
  shipped function's actual behaviour. The `update-docs` skill
  can flip statuses and add slice-log entries, but T-15.4.2 is
  the human-judgement piece.
- **Recommended sequence**: T-15.4.1 (creative — write the
  contract doc extension) → T-15.4.2 (judgement —
  methodology verify) → T-15.4.3 (deterministic —
  current-product-state) → T-15.4.4 (deterministic — roadmap +
  README) → T-15.4.5 (close-out). Same pattern as US-13.5 /
  US-14.3.
- **Expected working tree at commit**: 5 docs modified + 1 new
  doc (the story file itself) + 0 code touched.
- **Epic 15 closure summary**: after this story ships, Epic 15
  is fully closed with 3 stories Done (US-15.1, US-15.2, US-15.4)
  + 1 Cancelled (US-15.3). The drawdown card now answers "which
  positions drove this drawdown?" via the Contributors drawer —
  the headline deliverable Epic 15 promised.
