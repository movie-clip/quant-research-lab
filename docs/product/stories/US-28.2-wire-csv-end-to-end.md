# US-28.2: Wire CSV end-to-end — detection, upload UI, golden pipeline on IB2026.csv

**Epic:** Epic 28 — IBKR CSV Importer & Statement-Refresh Resilience
**PRD:** [`epic-28-ibkr-csv-importer.md`](../prd/epic-28-ibkr-csv-importer.md)
**Status:** Done
**Last updated:** 2026-07-07

## Story

As a **portfolio researcher**, I want to pick my CSV statement in the app and
have the whole product (import, dashboard, goldens, refresh flow) run off it,
so the CSV is the canonical current statement rather than a side path.

## Context

Depends on US-28.1 (the importer exists). Three `.pdf` gates plus the golden
pipeline keying:

1. `app/services/statement_importer.py` `import_statement` — raises on
   non-`.pdf`. Extend: `.csv` routes to the IBKR CSV importer (preview →
   import, same try-chain pattern); `.pdf` chain unchanged.
2. `apps/desktop/src/app/App.tsx` — line ~200 filters selection to `.pdf`;
   line ~854 `<input accept="application/pdf,.pdf">`. Both gain `.csv`
   (`text/csv`). Import-flow copy that says "PDF" becomes format-neutral.
3. Golden pipeline: `app/scripts/export_dashboard_goldens.py`
   `_docs_statement_path(..., "IB2026.pdf", fallback="2026.pdf")` →
   prefer `IB2026.csv` (fallback to the PDF names);
   `app/tests/_statement_fixtures.py` gains `STATEMENT_2026_CSV_PATH` and the
   IB2026-consuming tests move to it. `scripts/refresh_statement.py`
   docstring/messages updated (statement file may be `.pdf` or `.csv`).

**This story regenerates the dashboard goldens once, deliberately** — the CSV
covers 2026-01-01 → 2026-06-30 while the PDF covered Jan–Apr, so every
IB-derived golden value shifts (longer history window, sold/added positions,
new symbols). That requires the `refresh_statement.py` flow (frozen
market-data re-capture needs a real `FMP_API_KEY`) and registry entries for
any new holdings — budget for it; it is the story's main risk. Statement-truth
pins that fail (holdings symbols, ISIN/registry coverage, position counts)
are updated here — and catalogued as input to US-28.3's consolidation.

Implementer must read:
- `scripts/refresh_statement.py` (the recovery flow this story exercises for
  real) + `docs/architecture/testing-architecture.md` golden sections.
- `app/api/routes/imports.py` (upload path already suffix-agnostic — verify,
  don't change).
- `.claude/skills/fmp-data/SKILL.md` — adding tickers for new holdings.
